# 博衡中美跨境团队 IP 方案（供 Agent 评审）

## 一、项目背景

博衡律师事务所（Cathay Praxis Law, PC）是一家立足美国、专注于跨境法律服务的律师事务所。周争平律师为创始人，拥有中国及美国加州律师执业资格。团队业务覆盖跨境投资与并购、美国市场准入、出口管制与经济制裁、国际贸易合规、国际争议解决、知识产权、公司治理及监管合规。

项目现有品牌表达包括：

> 跨境有道 · 判断有衡

品牌升级目标：以博衡为机构基础，以周争平建立人物信任，以中美跨境法律实务形成内容辨识度，重新建立适合公众号、视频号、讲座和客户交流使用的团队 IP。

## 二、品牌共通原则

1. 主名称尽量简洁、易记，并与“博衡”或周争平形成稳定联系。
2. 副标清楚说明“周争平律师团队”“中美跨境法律实务”等身份信息。
3. 内容从企业真实问题出发，区分事实、法律分析、风险判断、可选路径和客户决策。
4. 视觉延续现有博衡 Logo 的双线交汇元素，避免法槌、天平、国旗、地球等泛化符号。
5. 所有名称仍需进一步核查公众号重名、商标及相关使用限制。

## 三、方案一：博衡观澜

### 定位

有观点的跨境法律观察者。

### 品牌表达

- 品牌主张：**跨境有道，判断有衡。**
- 英文辅助：**CATHAY PRAXIS INSIGHTS**
- 身份副标：**周争平律师团队 · 中美跨境法律实务**

“博衡”承接律所品牌，“观澜”容纳监管变化、跨境交易、商业争议和个人思考。适合把专业分析做出长期栏目感。

### 内容栏目

- **争平有话**：周律师署名观点。
- **交易案头**：交易结构、合同与谈判。
- **监管观察**：美国监管变化及企业应对。
- **争议复盘**：从争议回看决策与项目管理。

### Logo 方向：双线观澜

延续现有 Logo 的双线交汇图形，以两条平稳横线为基础，在中央形成克制的交汇和轻微起伏，表达不同法律与商业语境之间的连接与观察。

- 颜色：深海军蓝 `#0F172A`、钴蓝 `#2563EB`、暖白。
- 中文字体：清晰的现代宋体，字距略宽。
- 头像版本：交汇图形在上，“博衡 / 观澜”两行文字在下，不放细小英文。
- 封面版本：图形、品牌名、栏目名和核心问题四个层级。
- 气质：沉稳、开阔、具有专业刊物感。

### 主要取舍

“观澜”不直接说明业务，需要长期搭配业务副标；但整体最均衡，适合图文、视频和活动共同发展。

## 四、方案二：博衡知行

### 定位

把法律理解转化为具体行动的实务团队。

### 品牌表达

- 品牌主张：**知规则，明路径，重实务。**
- 英文辅助：**PRAXIS NOTES**
- 身份副标：**周争平律师团队 · 中美跨境实务**

“知行”与 Cathay Praxis 的实践意味联系最紧密，也呼应团队“清晰、及时、可执行、服务商业目标”的定位。

### 内容栏目

- **知规**：解释关键法律规则。
- **行事**：交易、尽调、合规与项目推进。
- **案中所得**：从实践提炼经验。
- **争平手记**：负责人对法律工作与商业问题的思考。

### Logo 方向：书页成径

以两片简洁书页构成图形，中央留白形成向前延伸的通道，表达从理解规则到落地执行。图形笔画与博衡现有 Logo 保持相近的厚度。

- 颜色：深蓝、灰绿、米白。
- 中文字体：结构扎实的现代黑体；文章标题可用宋体。
- 头像版本：图形加“知行”二字；完整名称用于封面和介绍页。
- 气质：务实、清楚、有方法感。

### 主要取舍

“知行”较常见，必须保留“博衡”前缀，并通过清单、流程和具体案例持续证明实务价值。

## 五、方案三：跨境有衡

### 定位

帮助企业厘清跨境决策的法律顾问。

### 品牌表达

- 品牌主张：**看清规则，权衡进退。**
- 英文辅助：**CROSS-BORDER PERSPECTIVES**
- 母品牌署名：**博衡 · 周争平律师团队出品**

“跨境”直接说明场景，“有衡”延续博衡和已有品牌主张，强调有依据、有尺度的分析。

### 内容栏目

- **决策之前**：项目启动前需要核实的问题。
- **条款之间**：合同安排背后的利益与风险。
- **监管之下**：监管规则如何影响业务。
- **争议之中**：诉讼、仲裁、谈判与执行路径。

### Logo 方向：尺度与交汇

两组开放折线从左右相向展开，中间设置一条平稳横线，表达不同立场和条件汇入同一分析框架。避免直接画成天平。

- 颜色：午夜蓝、少量古铜色、白色。
- 中文字体：简洁黑体，可对“衡”字作轻微定制。
- 头像版本：几何图形与“有衡”二字组合。
- 气质：理性、成熟、适合商务场景。

### 主要取舍

名称没有完整出现“博衡”，必须固定搭配母品牌署名，才能把内容影响力沉淀到律所品牌。

## 六、方案四：争平越洋

### 定位

周律师主理的中美跨境人物 IP。

### 品牌表达

- 品牌主张：**从中国企业的问题出发，谈跨境法律实务。**
- 英文辅助：**ZHOU ON CROSS-BORDER MATTERS**
- 团队署名：**博衡律师团队支持**

“争平”建立人物识别，“越洋”体现中美背景，也适合访谈、办案观察和跨境工作见闻。

### 内容栏目

- **争平说案**：围绕具体问题讲解案件。
- **越洋对谈**：与企业法务及专业人士交流。
- **谈判桌边**：合同与谈判观察。
- **案头与途中**：专业工作中的经验与思考。

### Logo 方向：Z 字越洋

以姓氏首字母 **Z** 为基础，上下横线形成两端，中间斜线连接两端；融入现有双线交汇元素，形成简洁的人物标识。

- 颜色：石墨蓝、暗酒红、暖白。
- 中文字体：稳健宋体，避免难辨认的签名字。
- 头像版本：优先使用周律师职业肖像；图形用于封面角标和视频片头。
- 气质：有个人温度，专业而直接。

### 主要取舍

对周律师持续参与要求最高。适合视频、演讲和访谈，但团队长期共同输出时需要明确署名规则。

## 七、方案五：博衡商法札记

### 定位

值得企业法务长期收藏的专业刊物。

### 品牌表达

- 品牌主张：**从规则到交易，从争议到实践。**
- 英文辅助：**CATHAY PRAXIS REVIEW**
- 身份副标：**周争平律师团队 · 中美跨境商法观察**

“商法”明确商业法律方向，“札记”保留作者感，适合分析文章、实务笔记和专题研究。

### 内容栏目

- **交易札记**：投资、并购与合同。
- **合规札记**：出口管制、制裁与经营合规。
- **争议札记**：诉讼、仲裁与执行。
- **判例札记**：围绕裁判理由分析实务影响。

### Logo 方向：刊物字标

以文字本身作为主体，“博衡”略小，“商法札记”为主标题；旁边用两条错位书页线构成辅助图形，现有交汇标识作为母品牌角标保留。

- 颜色：墨蓝、纸白、少量灰绿。
- 中文字体：宋体主标题，黑体用于栏目和日期。
- 头像版本：“博衡 / 札记”四字排版。
- 气质：克制、耐看，有编辑与研究气质。

### 主要取舍

名称稍长，视频传播感弱于人物型方案，更适合深度图文、研究专题和季度合集。

## 八、横向比较

| 方案 | 希望建立的认知 | 适合的运营重心 | 主要风险 |
|---|---|---|---|
| 博衡观澜 | 团队有视野、有观点 | 图文、视频、活动均衡 | 业务指向需靠副标说明 |
| 博衡知行 | 团队懂规则、重实践 | 实务文章、清单、方法分享 | 名称相对常见 |
| 跨境有衡 | 团队善于分析复杂选择 | 企业决策、专题简报 | 需要强化博衡母品牌 |
| 争平越洋 | 记住周律师本人 | 视频、演讲、访谈 | 依赖负责人持续出镜 |
| 博衡商法札记 | 内容值得反复查阅 | 深度文章、专题研究 | 名称偏长，视频感较弱 |

## 九、当前建议排序

1. **博衡观澜**：机构、人物和专业内容三者最均衡，适合作为长期团队 IP。
2. **博衡知行**：与 Cathay Praxis 的实践理念联系最紧，适合做具体方法和执行路径。
3. **跨境有衡**：业务定位最直观，适合企业决策者，但需要固定母品牌署名。
4. **争平越洋**：人物传播潜力强，适合周律师高频参与视频和访谈。
5. **博衡商法札记**：专业内容沉淀能力强，适合作为研究型栏目或专题品牌。

2. 哪个方案最能同时承接博衡机构品牌和周争平个人影响力？
3. 哪个名称在中文传播中最容易记忆、转述和搜索？
4. Logo 应该更偏向现有双线交汇图形，还是建立新的独立符号？
5. 是否需要把“中美”直接放入主名称，还是由副标和内容栏目体现？
6. 哪些名称需要优先做公众号、商标和同业名称查重？
